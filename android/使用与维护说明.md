# 星港合影 · 安卓离线版 0.6.0

开发：斯曼达洛舰队-Lemon_ACE

## 安装与使用

将 `星港合影-v0.6.0-安卓离线版.apk` 传到 Android 10 或更高版本的手机，打开文件并按系统提示允许此次安装。应用名称为“星港合影”。首次使用和日常操作均可断网，不需要账号或服务器。若系统 WebView 很旧，先更新 Android System WebView。

底部三个入口为“舰船库”“全家福”“个人名牌”。手机端通过“资料与设置 / 画布与清单”切换编辑和预览；平板和宽屏同时显示设置与画布。

* **舰船库**：保留 248 个型号、494 张透明舰船图片、中文社区名称和长度校准。可搜索、按制造商和类型筛选、编辑名称和尺寸、替换图片、点选船首船尾校准，以及备份和恢复图库。现有图库中的灰色模型仍保持灰色模型。
* **全家福**：保留成员与数量管理、Excel 名单导入、标准模板导出、CSV 名单、中心辐射与紧凑排列、拖动和锁定、Logo、标题位置和各项字号。说明文字逐项控制；固定开发者署名始终保留。
* **触屏画布**：双指缩放和平移，或使用缩放按钮。“移动舰船”修改舰船位置，“平移画布”只改变观看范围。“适应”恢复全图。手机缩放不会改变导出比例或舰船坐标。
* **个人名牌**：保留舰船选择、三张内置背景、自定义背景与 Logo、字体和颜色、各项说明开关。输出为 3200 × 1200 PNG。

## 文件保存、分享与迁移

图片生成后可选择“保存到相册”“另存为文件”或“分享”。相册位置为 `Pictures/StarportPortraits`；不同手机的相册应用可能将其显示为“StarportPortraits”相册。Excel、CSV、图库及工程备份可通过系统文件保存窗口选择位置，也可打开系统分享面板。

全家福支持普通清晰度（2400 × 1350）和 4K（3840 × 2160）。舰船较多时可使用紧凑排列，缩小成员及型号文字；若警告提示无法排下，先减少文字占位或解除锁定并重新排列。工程仍支持最多 200 艘 / 辆。

从电脑版迁移：在电脑导出完整“工程备份”，传到手机，在全家福中选择“导入工程”。安卓导出的完整工程也可在现有电脑版恢复，内含图库、图片、成员、Logo 和位置。个人名牌设置也会随完整工程保存，可另存名牌设置文件。

修改会自动暂存在应用内部。**卸载或清除应用数据前，请先保存工程备份**；重新安装不会自动读取电脑浏览器或手机浏览器的暂存数据。分享面板打开仅表示进入分享流程，重要备份建议另存为文件。

## 工程与构建

* 包名：`com.smandalo.starport`
* 版本：`0.6.0`，versionCode `600`
* 最低系统：Android 10 / API 29
* compileSdk / targetSdk：36，Build Tools：36.0.0
* Java：17；Gradle：8.13；Android Gradle Plugin：8.13.0
* 外壳：Java Activity、AndroidX WebViewAssetLoader、FileProvider、系统文件选择器和 MediaStore。
* 无 Internet 权限；网页资源从安装包本地加载。原版网页和资料文件没有修改。

工程 ZIP 内已经包含所有离线运行资源，可用 Android Studio 打开。构建工具首次配置需要联网下载依赖，用户安装后的运行不需要联网。

1. 安装 JDK 17 和对应 Android SDK。用 Android Studio 配置 SDK，或在本地 `local.properties` 填入 `sdk.dir=实际SDK路径`。
2. 测试版执行 `./gradlew assembleDebug`。
3. 正式版先把私有签名备份解压到工程根目录，执行 `./build-apk.sh`。结果为 `app/build/outputs/apk/release/app-release.apk`。

源码 ZIP 不包含私有密钥和密码。**签名备份请自行保留，不要与公开 APK 一起分发**。更新必须保留相同包名及签名，并增加 versionCode；覆盖安装通常保留内部数据，重要工程仍应备份。不要为后续版本重新生成签名。

维护网页时，可运行 `python3 prepare_web.py /电脑版fleet-library目录` 更新安卓资源。该脚本验证图片哈希，将内嵌图片改为本地文件，接入安卓文件导出，并保留跨平台的完整备份格式。图库备份导入只接受内嵌图片，不允许从备份加载外部网络图片。

`app/src/androidTest` 中的自定义 Instrumentation 使用真实 Android WebView 验证导入、绘图、导出和保存。先构建并安装 debug APK 与 androidTest APK，再执行：

```sh
adb shell am force-stop com.smandalo.starport
adb shell am start -W -n com.smandalo.starport.debug/com.smandalo.starport.MainActivity
adb shell am instrument -w com.smandalo.starport.debug.test/com.smandalo.starport.SmokeInstrumentation
```

测试期间保持调试版位于前台，系统保存窗口需要实际可见。正式版的系统文件选择与 Excel 导入另有真实触屏验证截图。
