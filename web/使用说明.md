# 星港合影 · Starport Portraits 0.5.1

包含个人名牌制作、社区中文名称、可编辑舰船图库、官网长度比例、Excel 成员名单导入与舰队全家福编辑器。完全在本机运行，无需账号、安装、服务器或网络。

## 打开与开始使用

- 文件夹版：双击本文件旁的 `index.html`，保留 `data/library.js` 及页面代码文件。
- 单文件版：双击另外交付的 `舰队全家福-离线版.html`，图片和程序已全部嵌入。
- 推荐使用电脑上的现代 Chrome、Edge 或 Safari。页面顶部和左侧均可进入“成员与全家福”。
- 在成员页面点击“载入示例舰队”，可查看 15 艘舰船的示范。示例成员不代表真实舰队资料。
- 添加成员名称、舰船型号和数量，点击“添加到舰队”。自动排列把大船置于中心，小船向外展开。
- 画布支持点击、拖动、锁定；选中后可用方向键移动，Shift + 方向键加快。锁定位置会在自动排列中保留。
- 清单中的名称、数量可直接修改；点击“修改”可更换舰船型号。点击“删除”移除该条拥有记录。
- 可修改标题、副标题、字号、间距、背景和队徽。成员名称不会写进素材图片。
- 在“画布与比例”中，标题下方点击“上传 Logo”，可选择 5 MB 内的 PNG、WebP、JPEG，推荐透明 PNG。Logo 按原比例显示在自定义标题左侧，标题与副标题会自动右移；可随时更换或移除，并随工程备份保存。
- “导出 4K 大图”生成 3840 × 2160 PNG，保留成员名、型号、长度和比例尺。选框和锁定标记不进入成图。
- 右下角固定显示“开发：斯曼达洛舰队-Lemon_ACE”，全家福和个人名牌的预览、导出图片均保留。

## 标题区位置与说明文字

全家福的“画布与比例 → 标题区位置”支持左对齐、居中、右对齐和自定义位置。标题、副标题与 Logo 作为一组移动；居中和右对齐按实际文字宽度计算。自定义 X / Y 以 2400 × 1350 画布左上角为起点，表示整组内容左上角的画布像素坐标；系统按实际宽高限制位置，避免越出边界或覆盖开发署名区。自动排列会避让自定义标题区；若锁定舰船造成冲突，可解除锁定再排列。手动拖动仍需自行检查重叠。

全家福和个人名牌的预览区均有“说明文字 · 逐项显示”，每个复选框独立生效，预览与导出同步。

- 全家福：工具英文标识、成员与舰船统计、舰船型号、舰船长度、比例尺、视角与比例说明、来源与数据快照。可以保留型号而只隐藏长度，也可以只保留比例尺。
- 个人名牌：英文栏目与档案标题、舰船中文名、舰船英文名、制造商、舰船长度、视角说明、背景来源说明。长度与视角即使原本位于同一行，也能分别隐藏，系统会自动处理分隔符。

保留“全部显示 / 全部隐藏”快捷按钮。填写的标题、副标题、成员姓名、名牌舰队名称与签名、Logo、舰船图片和固定开发署名不受这些开关影响。操作帮助、缺图或排列错误等提示仍留在编辑界面中。

两类作品分别保存逐项选项，随工程备份保留；名牌设置文件也包含名牌逐项选项。0.5.0 工程会把原来的整体显示 / 隐藏状态转换为相应的逐项状态；更早工程沿用显示说明及原有型号标签偏好，名单与图片继续保留。

## 个人名牌

在左侧或顶部点击“个人名牌”，填写成员名称、舰队名、称号或签名，搜索并选择一艘舰船。支持斜俯视 / 俯视；舰船在名牌中按构图大小显示，不作为不同舰船的长度比较。当前视角缺图片时会提示，并阻止缺船导出。

内置 3 张 RSI 官方公开背景：孟加拉·星海远航、孟加拉·舰队出击、克拉克·探索之旅。图片全部内嵌，无需联网。可以上传 12 MB 内的 PNG、WebP、JPEG 作为自己的背景，调整背景压暗和上下取景。背景来源与原始文件哈希见 `backgrounds/sources.json`；游戏图片归 CIG / RSI 所有，用于本地非商业玩家名牌。

可以独立上传名牌 Logo（5 MB 内），或使用全家福已有的 Logo；支持更换和移除。名字字号、签名字号、舰船显示大小、强调色均可调整，图片保持原比例。点击“导出个人名牌”生成 3200 × 1200 PNG。

“保存名牌设置”生成 `.nameplate.json`，包含文字、选择的型号、背景参数、上传的背景与 Logo；“导入名牌设置”可继续修改。这个轻量文件引用当前图库的型号 ID；自定义型号需要保留对应图库。“保存工程备份”仍会保存完整图库，并且同时包含名牌设置，适合换电脑恢复。

## 全家福字号与紧凑型排列

在“画布与比例”中可分别设置标题（16–56 px）、副标题（8–28 px）、成员名（6–40 px）和型号（6–28 px）。字号为 2400 × 1350 画布像素，4K 导出时一起放大。成员名 / 型号字号或显示状态改变时，标签占位会重新计算。大量舰船建议成员名 8–12 px、型号 6–9 px，也可关闭型号文字；过小文字需要放大成图阅读。

“排列方式”有“中心辐射排列”和“紧凑型排列”。紧凑型从大到小放置舰船，把小船填进大船之间可用的空隙；舰船与标签均参与碰撞检查，整张图始终共用同一米制比例，不能单独放大小船。原本默认 22 px 间距首次切换紧凑型时会改为 8 px；可自行设置 0–60 px，建议 4–8 px。可保留锁定位置，必要时解除锁定再重排。它利用矩形占位间的空隙，不把小船压进大船轮廓内部或透明凹口。

旧工程导入时补齐新增设置，原名单、图片、尺寸与位置继续保留。

批量录入位于左侧折叠区，每行 `成员名称,英文型号,数量`。支持引号内的逗号，例如 `"Member, A",Carrack,1`。也接受中文显示名及已录入的俗称，但必须唯一匹配。发现错误时整批不写入，提示出错行；修正后再提交。可导出带 BOM 的成员 CSV。

## 标准模板填报

成员页提供“下载标准 Excel 模板”，模板有 500 行空白填写区和 248 个标准名称下拉选项。采用每行一种型号的格式：username 必填，ZH 选填，舰船型号从中英文完整名称下拉框选择，数量留空按 1 艘或填写 1–50 整数。同一成员的多种舰船分行填写，并重复 username；导入后自动按成员与型号累计数量。舰船目录可筛选制造商、社区中文名与英文型号，也可复制第一列的完整标准名称到填报页。保留舰船目录，以免破坏下拉来源。

模板为 .xlsx，无宏、无需联网。目录同时保留型号 ID、素材情况和名称来源，缺图型号仍可登记并在全家福中提示未入画。查无型号时在备注说明，由负责人核对后补充；备注本身不会新增舰船。下拉允许空白预留行；输入非列表名称或错误数量会触发 Excel 校验提示，粘贴后的内容仍由离线工具再核对。

请使用 0.3.1 或更新版离线工具导入这个中英文标准模板。旧的 ship1…ship21 表格继续兼容。

## 从 Excel 导入

1. 在“成员与全家福”点击“导入 Excel 名单”，选择 `.xlsx / .xls / .xlsm`。解析程序已内置，文件在本机读取；不执行公式或宏，公式只读取已有缓存结果。Excel 错误值或无缓存公式会提示修正原表。
2. 默认识别表头 `username / ZH / ship1 … ship21`，优先打开含成员和舰船列的工作表。仅导入选定的那张表，不会把花名册、非舰队人员等其他表自动加入。
3. 可更改工作表、表头行、成员列、昵称列、舰船列；也支持“每艘一行”的 `成员 / 舰船型号 / 数量` 明细格式。
4. 可选择图片上显示 username、ZH 优先，或 `ZH (username)`。不论显示哪个，成员 ID 仍用 username，避免两人中文昵称相同而合并。
5. 每个非空 ship 单元格计一艘，相同成员重复填写同一型号会累计数量。未填写舰船的行会统计为空行，不会生成舰船。
6. 大小写、空格、连接符及完全相同词项的顺序可以统一匹配。简称、错字、缺少具体变体的名称不会自动选中候选。默认只显示待确认条目，也可查看并修改所有已识别对应关系。
7. 每个待确认名称必须选择具体图库型号，或选择“明确跳过”。预览逐项显示成员、原文、型号、数量与来源单元格。未确认、无效数量或超过画布上限时，不能应用。
8. 选择“追加”或“替换当前清单”。替换保留标题、背景等画布设置，移除旧成员和位置。整批校验通过后一次应用；同一文件和列设置再次追加会拦截，避免重复累计。
9. 可在本工程记住这次对应关系（包括明确跳过），下次导入会带入并可在全部条目中修改。保存工程备份会包含成员、对应关系、导入记录和来源单元格。图库备份不含这些工程信息。
10. “下载名称匹配记录”仅输出型号对应、数量和列设置，不包含成员名单。导入后可继续在清单修改舰船及数量，点击自动排列，再导出全家福。

针对提供的样表，已用实际文件验证读取 3 张表；主表 147 行成员记录中 19 人填有舰船，81 个非空舰船单元格。程序会恢复导出文件中 `!ref=X148` 这类不完整范围标记，按真实单元格读取，不会只读最后一格。统计只用于本地验证，成员资料没有作为默认名单打包。具体歧义见 `Excel名称核对说明.md`。

支持 20 MB 以内文件，每表最多 10000 行、256 列。单张画布仍为 200 艘上限；较大舰队请分工程导入。

## 社区中文名称（本版新增）

248 个型号使用可追溯的社区名称：245 项来自星际公民汉化组 LocalizationData，3 项来自中文百科。只移除制造商前缀，没有自行翻译型号；部分数字型号在社区文本中也保留英文代码。每个型号的详情内可查看名称来源与原始字符串，逐项记录位于 `data/community-names.json / .csv`。

例如 Carrack 使用“克拉克”，Cutter 使用“小刀”，Salvation 使用“拯救”。Tiburon 的社区俗称“激光鲨”另有社区讨论出处，可用于搜索和导入。中文名和自定义俗称仍可修改；全家福标签与成员清单优先显示中文名，清单同时保留英文。

名称文本的署名和使用许可见 `中文名称来源与许可.md`；汉化组文本为 CC BY-NC-SA 4.0。

## 比例如何建立

数据快照：2026-10-21。248 个型号、494 张透明图片；其中 245 个型号按官方型号 ID 匹配到 RSI 官网详情，244 个有俯视图并建立官网长度关系。3 个没有匹配官方 ID 的型号保留第三方长度：600i Executive-Edition、Bengal、Dragonfly Starkitten Edition。ATLS IKTI Akuma 仍缺图片。

默认使用 RSI 官网详情页提供的结构化 Length（单位米）；另保存官方 Ship Matrix 的 length / beam / height。所有原始 FleetYards 和 Wiki 尺寸继续保留在记录里。详情页可切换“官网详情页 / 官网矩阵”，也可以人工输入长度。

1. 读取图片实际 Alpha 通道，按 Alpha ≥ 8 测量可见轮廓边界，排除透明留白。
2. 俯视素材的纵向在图片 X 轴上，默认用轮廓 X 跨度作为舰长像素参考。
3. `素材像素/米 = 参考像素跨度 ÷ 舰船长度（米）`。
4. `绘制倍率 = 画布像素/米 ÷ 素材像素/米`。同一张图所有船共用“画布像素/米”，横纵使用相同倍率，保持原图形状。

例如默认官网详情长度：Polaris 166 米、Carrack 126.5 米、C2 Hercules 94 米、100i 19.3 米。俯视轮廓纵向显示长度之比为 `166 : 126.5 : 94 : 19.3`，不会因为小船难看清而单独放大。

这建立了可追溯的长度关系，并不等于每艘原始模型都已完成几何测绘。当前有 178 个型号的官网详情与矩阵在至少一个尺寸轴相差超过 1%；37 张俯视图的轮廓长宽比与默认官网长宽比相差超过 20%。可能涉及旧参数、姿态、机翼、炮管或原站素材；均已记录并提示。不会强行把图片的宽高分别拉伸去符合参数。

斜俯视图存在透视，单凭一个官网舰长无法求出真实相机投影。本版保留该视角用于展示，明确标记“斜俯视投影近似”；比较舰长请使用俯视模式。

## 人工校准与图片替换

进入“舰船素材库”，切到需要校准的视角，再点击舰船卡片。

- 可查看官网详情值、矩阵值、历史第三方尺寸及来源地址，选择尺寸依据后保存。
- 点击“点选船首与船尾”，在显示的测量图中依次点两点，再保存。记录两点坐标、距离和对应的舰长；也可直接填写已知像素参考。
- 测量线必须对应输入长度的同一物理区间；不要把不对应舰长的机翼斜线当成纵向长度。
- 替换图片后原像素参考会清空，需要重新测量。新图片可用 PNG、WebP、JPEG，最大 20 MB / 4000 万像素。
- 不透明图片会提示；程序不会自动把不透明图片当成已抠图。库内初始 494 张素材均有真实透明通道。
- 新增自定义型号时填写正数长度，补充图片，并为每个使用的视角设置像素参考。

缺少图片、长度或参考跨度的舰船不会被伪造占位图替代。它们保留在成员清单，“未入画”提示与导出页脚会注明数量。

## 保存、备份和旧版升级

有两种备份，作用不同：

- 顶部“导出图库备份”生成 `.fleetlib.json`：包含图库、图片和素材修改，不含成员工程。
- 成员页面“保存工程备份”生成 `.fleetproject.json`：包含全部图库、成员、标题、位置、锁定、队徽和比例。日常推荐保存此文件，可直接在另一台电脑“导入工程”继续编辑。

网页尝试使用 IndexedDB 自动暂存，状态以提示为准。文件位置、浏览器、无痕模式、清理浏览器数据都会影响暂存。正式保存请保留导出的 JSON 文件。程序不会直接改写交付文件夹里的 JSON、SQLite、原始图片或 HTML。

导入 0.1 素材备份、或恢复本浏览器的 0.1 暂存时，会升级官网长度及初始素材校准；保留自定义型号、替换图片、人工尺寸、修改过的名称和已有人工参考。导入 0.1 / 0.2 备份时，初始中文名称升级为本版社区名称；人工更改过的显示名、尺寸和素材保留。0.3 备份按自身内容恢复。

单张画布最多记录 200 艘 / 辆，每条拥有记录数量 1–50。舰船数量多或名称很长时，标签会占较多面积：可缩小字号、减少间距、缩短显示名或拆分工程。程序会整体缩小舰船以保持同一比例；无法安排时会提示并保留清单。手动移动允许重叠，并提示检查。

## 数据与代码文件

- `data/library.json`：完整结构资料，不内嵌图片二进制。
- `data/library.js`：网页启动数据库，含全部图片 Data URL，用于直接双击打开。
- `data/fleet-library.sqlite`：离线关系数据库；`ships / assets / metadata` 三表。页面不直接连接 SQLite。
- `data/ships.csv`：当前型号与尺寸清单。
- `data/community-names.json / .csv`：248 个型号的社区原始名称、显示名和来源。
- `data/scale-relations.csv`：详情长度、矩阵长度、采用长度、相对 100 米的比例与像素换算。
- `data/official-dimensions.json`：245 个型号的官方 ID、官网两套数值、选择依据、采集日期和详情页哈希。
- `data/calibration-report.json`：官网差异、素材比例异常及计算公式。
- `data/sources/`：官方矩阵原始 JSON、详情页结构化 Product 数据的离线快照。
- `data/audit.json`：原始素材审计及本版校准统计；`data/verification.json` 记录验证范围。
- `assets/`：494 张下载后保持原字节的透明 WebP；约 28.3 MB，最长边通常不超过 1000 像素。
- `index.html / app.css / app.js`：图库界面。
- `fleet-engine.js / fleet.css / fleet.js`：比例与布局引擎、成员编辑器与 Canvas 导出。
- `nameplate.js / data/nameplate-backgrounds.js`：个人名牌编辑器与内嵌背景；`backgrounds/` 保存原始背景和来源记录。
- `excel-engine.js / excel.js`：本机表格识别、保守名称匹配、导入预览与一次应用。
- `vendor/`：SheetJS 0.20.3 离线解析器及 Apache 2.0 许可。

原始素材有 105 个型号具备彩色版本、142 个型号只有灰模、22 组跨型号复用图片；共享模型、变体涂装和小细节仍需要人工复核。4K 指画布输出尺寸，不会增加原始图片的真实纹理分辨率。
